# Agent 评测说明

当前评测分为三层，不能混用结论：

1. `pnpm eval:agent`：只检查 48 条场景 fixture 的数量、字段、ID 和 Agent 覆盖；不会调用模型，也不证明回答质量。
2. `pnpm eval:agent:api`：调用正在运行的本地 `/api/agent`，验证三问后的阶段判断可区分“继续推进 / 先暂停 / 补信息”。未配置 AI Key 时，结果来自确定性演示逻辑。
3. 真实模型效果评测：需要配置模型后，逐条运行 48 条场景并完成人工评分。目前尚未完成，不能宣称达到上线门槛。
