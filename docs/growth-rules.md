# 好好值规则

好好值用于记录用户是否认真完成了“想清楚—行动—回看”的过程，不用于衡量消费能力，也不会因为花得更多而获得更多分数。体验是好是坏不会改变奖励，避免为了分数写出不真实的“好评”。

## 页面入口

用户可以在“我的”页直接看到好好值的简短说明，并从成长卡片右上角的“规则与明细”查看完整计分、限制条件和每一笔变化。在“我的果实”完成首次回看时，页面也会明确提示本次可获得 +15 好好值。

## 当前计分

| 行为 | 分值 | 限制 |
| --- | ---: | --- |
| 为一个心愿写下最终决定理由 | +20 | 每个心愿一次 |
| 首次为一件已有物品记录真实体验或反思 | +15 | 每件物品一次；选择正面或负面体验分值相同，后续记录不重复加分 |
| 完善昵称和个人简介 | +10 | 每个账户一次 |
| 认领一份有效的朋友回信 | +10 | 同一回信不可重复；每天最多 3 次获得分数 |

以下行为不加分：消费金额、邀请人数、连续登录、收到多少赞同，以及是否跟随多数意见。

## 等级

| 等级 | 好好值 |
| --- | ---: |
| LV.1 | 0–99 |
| LV.2 | 100–299 |
| LV.3 | 300–699 |
| LV.4 | 700 及以上 |

计分写入成长流水，并使用“行为 + 对象”的唯一标识防止重复奖励。规则如有调整，应同时更新本文件、服务端计分逻辑和个人页中的说明。

## 物资回看与归档

课程或次卡次数用完、一次性体验完成、储值余额归零，或任意物资超过有效期后，会进入“待回看”。用户完成回看后，物资从当前列表隐藏并进入“过去的果实”；物资本身、使用次数、每次价格和体验记录都会保留，不做物理删除。
